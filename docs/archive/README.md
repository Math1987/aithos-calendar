# Archive

Documents written before the trust layer (September 18, 2026). They record
earlier gates, manual tests and the previous design in which agent cards were
published to an external registry and the discovery client trusted an origin
allow-list. They are kept for history and are not maintained: identifiers,
URLs, environment variables and file names they mention may no longer exist.
The current references are `docs/trust-layer.md`, `docs/trust-manifest-evaluation.md`,
`docs/sdk-capabilities.md` and `docs/logging.md`.

`HANDOFF-trust-layer-poc.md` (and its addendum) are the French task briefs the
trust layer was built from.
